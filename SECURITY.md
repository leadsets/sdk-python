# Security policy

## Reporting a vulnerability

Please report security issues privately to **security@leadsets.ai**. Don't open a public issue.

Include what you found, how to reproduce it, and the SDK version. We'll acknowledge your report
within 3 business days and keep you updated until it's resolved.

## Supported versions

Security fixes go into the latest released version.

## API keys

Never put an API key in client-side code, a public repository or an issue. If a key leaks,
revoke it in the dashboard and create a new one.
